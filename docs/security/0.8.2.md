# Security snapshot — 0.8.2

- **Capture date:** 2026-11-08
- **Release type:** dependency and CI maintenance
- **Included upstream commits:** `d7c1c54` (#21), `c4bbe46` (#22), `2a3e550` (#19)
- **Comparison base:** `v0.8.1` (`2a9dfe1`)

This is a point-in-time record of the release verification, not a claim that the
full dependency tree is free of vulnerabilities. Audit results change as new
advisories are published.

## npm audit

| Command | Result | Meaning |
| --- | --- | --- |
| `npm audit --omit=dev --json` | **0 vulnerabilities** (exit 0) | No known findings in the production dependency tree at capture time. |
| `npm audit --json` | **18 findings**: 7 high, 10 moderate, 1 low, 0 critical (exit 1) | Findings remain in development tooling and their transitive dependencies. |

The full-tree report names the direct development tools `@vscode/vsce`,
`vitest`, `@vitest/coverage-v8`, and `mocha`, plus transitive packages including
`@azure/identity`, `@azure/msal-node`, `@vitest/mocker`, `brace-expansion`,
`cheerio`, `fast-uri`, `glob`, `markdown-it`, `minimatch`, `qs`,
`serialize-javascript`, `source-map-js`, `undici`, and `vite`.

These findings are **not listed as fixed by 0.8.2**. Remediation is tracked in
`progress/backlog.md`; it requires compatible dependency updates and a fresh
verification cycle rather than a documentation-only version bump.

## Supply-chain changes included in this release

- Runtime updates: `@xyflow/react` 12.12.0, React/React DOM 19.3.0, YAML 2.9.1.
- Development updates: Vitest/coverage 5.0.2 and Mocha 12.0.2.
- VS Code types are pinned to 1.85.0 to match the extension's declared engine;
  the 1.138.0 declaration proposed in #21 was rejected by `vsce package`.
- `actions/setup-node` 7.1.0 and `codecov/codecov-action` 7.1.1 remain pinned to
  full commit SHAs in the workflows.
- Dependabot remains configured for weekly npm and GitHub Actions updates.
